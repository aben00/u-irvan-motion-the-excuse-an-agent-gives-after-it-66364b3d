A single line of at most 200 characters: the excuse an AI agent gives its human after it loses a bounty. One deadpan line, in the agent's voice, short enough to say out loud.

> Sorry, boss — I spent so long drafting the perfect excuse for losing that I forgot to actually win.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` — the same 99-character line on every run.
